使用 Sony `YUC00574.ARW`（9984 × 6656）检查 −1 / 0 / +1 / +0.37 EV，并目视检查实际 Qt 窗口渲染截图。测量在本机后台事件循环中进行；性能可能随硬件与负载变化。

输出完整解码与 EXIF 回读校验通过，逐张 JSON 记录 `exposure_ev: 0.37`。详情见 [测量记录](exposure-validation.json)，界面见 [曝光截图](exposure-dialog.png) 和 [主界面](interface-v03.png)。没有重新测量新版输出在 FOTOS 内的处理速度。

本版更换 RAW 中性亮度基准与 sRGB 转移函数，0 EV 不保证与 v0.2 像素一致。预览剪裁警告依据缩小后的显示 RGB，不是传感器饱和度；已在 RAW 开发或 JPEG 输入中剪裁的细节不能保证恢复。没有实现 Capture One 私有色彩引擎、高光重建或镜头像素校正。
